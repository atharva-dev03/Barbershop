# Jadhav & Son's Barbershop Website

## Overview

Jadhav & Son's is a modern and responsive barbershop website designed to showcase premium grooming services, experienced barbers, and business information. The website features a clean user interface with a professional dark theme, smooth hover effects, and a mobile-friendly layout.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Modern hero section with call-to-action button
* About Us section introducing the barbershop
* Services section highlighting available grooming services
* Team section showcasing professional barbers
* Footer with contact information and navigation links
* Smooth hover effects and attractive styling
* Fixed navigation bar for easy browsing

## Technologies Used

* HTML5
* CSS3
* Font Awesome Icons
